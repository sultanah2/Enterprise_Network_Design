# Enterprise_Network_Design

## Overview
This project demonstrates the design and implementation of an enterprise network using Cisco Packet Tracer.

## Features
- VLAN Configuration
- Router-on-a-Stick (ROAS)
- RIP Routing
- Access Control Lists (ACL)
- Network Segmentation
